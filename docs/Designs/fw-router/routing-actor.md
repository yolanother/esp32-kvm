# Firmware routing actor

`firmware/components/router/router.h` is the single serialized route gate. Its caller owns the actor thread and supplies monotonic firmware milliseconds. The USB transport validates framing and payload lengths, then passes the decoded session, sequence, route generation, and report to this API. The current transport loopback does not yet dispatch these messages; wiring it and the device event loop is an integration task. Do not call this actor concurrently from USB and GAP callbacks.

At startup call `kvm_router_init`, then `kvm_router_session_open` only after `SESSION_OPEN` has been validated and ACKed. On USB disconnect, device reset, or a new session, call `kvm_router_reset`/`kvm_router_session_open`. `SWITCH` releases the selected guest, clears its pending input, installs the requested generation, selects the target, and ACKs disarmed. `ARM` requires a ready target and an all-up baseline from the output callback. A valid `RELEASE_ALL` disarms and advances the generation. All-up delivery failure calls `disconnect`, and no new input is accepted on that path. Slot zero is local and cannot be armed. The present HID implementation has one guest, so router slots are zero or one.

The output adapter should map `ready(1)` to the bound HID channel's connected, encrypted, all-report-subscribed state; `arm(1)` to `hid_channel_arm`; `release(1)` to `hid_channel_release`; and `send(1)` to the matching `hid_channel_keyboard`, `hid_channel_mouse`, or `hid_channel_consumer`. The adapter's `disconnect(1)` must terminate the physical NimBLE connection when all-up delivery is uncertain. USB `ACK`/`NACK` uses the returned result and `router.last_result_generation` for accepted or cached controls. `STATUS` uses `router.slot`, `router.armed`, `router.fault`, and `router.generation`.

Call `kvm_router_tick` frequently, including while USB is idle. Only a fresh, valid monotonic host heartbeat renews the 500 ms lease. Input is tagged with generation and bounded to eight events. A full queue fails local. Relative motion over 50 ms old is discarded. If output remains unable to enqueue for 100 ms, the router releases and fails local rather than replaying queued input. Control retries with the same session and sequence return their cached result; changed content on the same sequence is rejected. The caller must resession before modular sequence ordering becomes ambiguous.

Portable source gate: `Set-ExecutionPolicy -Scope Process Bypass -Force; & ./firmware/tests/router/run-msvc.ps1` from the repository root. This checks the actor with a fake output. ESP-IDF build, USB dispatcher wiring, NimBLE output wiring, and physical lease/disconnect behavior remain unverified until integration and board bring-up. No board pins or flash actions are owned by this component.
