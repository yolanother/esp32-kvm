# Firmware routing actor

`firmware/components/router/router.h` is the single serialized route gate. The USB Serial/JTAG worker owns it and supplies monotonic firmware milliseconds from `esp_timer_get_time`. The transport validates framing and payload lengths, then dispatches decoded session, sequence, route generation, and report values. `kvm_transport_core_tick` drains input and enforces the lease while USB is idle. GAP callbacks do not call the router.

At startup call `kvm_router_init`, then `kvm_router_session_open` only after `SESSION_OPEN` has been validated and ACKed. On USB disconnect, device reset, or a new session, call `kvm_router_reset`/`kvm_router_session_open`. `SWITCH` releases the selected guest, clears its pending input, installs the requested generation, selects the target, and ACKs disarmed. `ARM` requires a ready target and an all-up baseline from the output callback. A valid `RELEASE_ALL` disarms and advances the generation. All-up delivery failure calls `disconnect`, and no new input is accepted on that path. Slot zero is local and cannot be armed. The present HID implementation has one guest, so router slots are zero or one.

`firmware/components/transport/router_hid_bridge.c` maps slot one to bounded `hid_guest_request_*` calls. They marshal readiness, arm, release, and report sends onto the NimBLE host loop; the USB worker never accesses `hid_channel_t` directly. The disconnect callback queues `hid_guest_request_disconnect` after uncertain all-up delivery. A failed or timed-out request is not treated as an ACK. USB `ACK`/`NACK` uses the returned result and `router.last_result_generation` for accepted or cached controls. `STATUS` uses router state and samples guest readiness when emitted, at most once per second without other state changes. A zero bond token is reported until persistent guest identity is connected to status.

Call `kvm_router_tick` frequently, including while USB is idle. Only a fresh, valid monotonic host heartbeat renews the 500 ms lease. Input is tagged with generation and bounded to eight events. A full queue fails local. Relative motion over 50 ms old is discarded. If output remains unable to enqueue for 100 ms, the router releases and fails local rather than replaying queued input. Control retries with the same session and sequence return their cached result; changed content on the same sequence is rejected. The caller must resession before modular sequence ordering becomes ambiguous.

Portable source gates from the repository root: `Set-ExecutionPolicy -Scope Process Bypass -Force; & ./firmware/tests/router/run-msvc.ps1` checks the actor; `& ./firmware/tests/integration/run-msvc.ps1` checks encoded USB dispatch, the legacy transport fixtures, and the HID adapter. ESP-IDF build, NimBLE task timing, and physical lease/disconnect behavior remain unverified until board bring-up. No board pins or flash actions are owned by this component.
